# Low Strain (Test)

Local test brand for the Lucid Labs theme factory — a palette tuned for tired eyes.
Not published to the marketplace.

- Warm-neutral surfaces instead of pure black/white (avoids halation)
- Every syntax token inside a narrow 7–10:1 contrast band, so the eye stops re-accommodating along a line
- Desaturated hues, no saturated red or blue text (chromatic aberration)
