# Draffin Street Furniture

A crisp VS Code colour theme pairing Draffin red with powder-coat charcoal, inspired by the Draffin Street Furniture visual identity.

## Brand Colours

| Colour | Hex | Role |
|--------|-----|------|
| **Logo Red** | `#ED3A28` | Logo squares, brand mark |
| **Web Red** | `#BC2114` | Buttons, badges, light-theme accent |
| **Ink** | `#221E1F` | Logo panel, light-theme status bar |
| **Charcoal** | `#323232` | Dark surfaces |
| **Steel Grey** | `#BABCBE` | Secondary text |
| **Concrete** | `#EFEFEF` | Light neutral surfaces |

## Dark Theme

- **Background**: Ink charcoal (`#1E1B1C`)
- **Text**: Warm off-white (`#ECEAEA`)
- **Keywords**: Coral red (`#F27A6C`)
- **Functions**: Brass (`#E8C886`)
- **Strings**: Park sage (`#A8C79A`)
- **Constants**: Timber amber (`#E0A562`)
- **Buttons/badges**: Draffin red (`#BC2114`)

## Light Theme

- **Background**: Clean white (`#FFFFFF`)
- **Text**: Ink (`#221E1F`)
- **Keywords**: Draffin red (`#BC2114`)
- **Functions**: Timber brown (`#8A4B0F`)
- **Strings**: Forest green (`#3D6B30`)
- **Constants**: Steel blue (`#1F5A85`)
- **Status Bar**: Ink with a red top rule

## Installation

1. Open VS Code
2. Go to Extensions (Ctrl+Shift+X / Cmd+Shift+X)
3. Search for "Draffin"
4. Click Install
5. Select the theme: File > Preferences > Colour Theme
